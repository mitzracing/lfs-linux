Small enough to audit

The wrapper is Bash, desktop metadata, and documentation. A single release manifest records exact versions, byte sizes, hashes, and complete extracted-tree postconditions.

  • Official LFS installer downloaded only after user confirmation
  • Exact Wine 11.15-1 archive and every runtime file verified
  • Every immutable stock game file checked before launch
  • Official DXVK archive with a private 32-bit D3D9 DLL
  • No update network request in the launch hot path
  • Unexpected executable or runtime drift blocks launch
  • Package removal preserves player data by default
  • Destructive removal requires explicit confirmation

Low maintenance

A launcher, not a fork

Normal changes are one manifest update, one compatibility patch, or one metadata edit. Contributors do not need game source, proprietary SDKs, or a permanent service.
