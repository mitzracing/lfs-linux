# Flathub Gate

No Flatpak manifest exists here by design.

Current Flathub requirements accept Wine-based Windows applications only when upstream submits and intends official maintenance.

Creating a community submit-ready manifest now would not satisfy that rule. It could also imply product authorization that this project does not have.

Proceed only after all authorization conditions in [`../../docs/FLATHUB.md`](../../docs/FLATHUB.md) are satisfied.

After authorization, create the manifest in an upstream-controlled repository or a repository explicitly approved by upstream.
